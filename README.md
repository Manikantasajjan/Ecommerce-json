# 🛒 Cartify - MERN E-Commerce Application

Cartify is a modern full-stack E-Commerce web application built using React.js and JSON Server. The platform provides a seamless shopping experience for users while offering a dedicated admin panel for product management.

## 🚀 Features

### User Module

* User Registration & Login
* Browse Products
* Product Search Functionality
* View Product Details
* Add Products to Cart
* Place Orders
* Responsive User Dashboard

### Admin Module

* Secure Admin Login
* Add New Products
* Manage Product Inventory
* View Product Listings
* Product Management Dashboard

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router DOM
* Axios
* React Toastify
* CSS3

### Backend

* JSON Server (Mock REST API)

### Development Tools

* Vite
* VS Code
* Git & GitHub

## 📌 Highlights

* Responsive and user-friendly UI
* Component-based React architecture
* REST API integration using Axios
* Dynamic routing with React Router
* Real-time notifications using React Toastify
* Clean and maintainable code structure

## 🎯 Project Objective

The goal of this project is to demonstrate full-stack web development concepts including authentication, product management, API integration, routing, state management, and responsive UI design through a real-world E-Commerce application.
